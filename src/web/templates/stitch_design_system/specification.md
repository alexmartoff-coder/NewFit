# Техническое Задание (ТЗ) и Архитектура Web-версии NewFit

Настоящий документ содержит полную техническую спецификацию для переноса экосистемы **NewFit** (фитнес, спорт, бьюти и ракетно-командный спорт) из Telegram-бота в полноценное веб-приложение (Telegram WebApp / SPA Web Application).

---

## 1. Обзор Системы и Пользовательские Роли

### 1.1 Роли Пользователей

1. **Клиент (`client`)**:
   - Поиск специалистов по городу, специализациям и категориям (Тренеры, Бьюти, Теннис, Падель).
   - Просмотр карточек специалистов, их фотогалереи, цен и отзывов.
   - Мультивыбор и бронирование свободных слотов на определенный день.
   - Управление своими записями (просмотр активных/прошедших, отмена записи с подтверждением, повторная запись).
   - Ведение списка «Избранные специалисты».
   - Оставление оценок и отзывов по завершению услуги/занятия.
   - Управление личным профилем и самоудаление аккаунта.

2. **Профессионал / Specialist (`trainer`, `beauty`, `tennis`, `padel`)**:
   - Прохождение первичного онбординга (город, район, специализации, имя, телефон, опыт, цены за 12 занятий / комплексные услуги, фотогалерея).
   - Модерация профиля (статус `pending` -> `approved` / `rejected`).
   - Кабинет профи (`pro_cabinet`):
     - Управление расписанием: быстрый конструктор автогенерации слотов (окно 7, 14, 30 дней, шаг 60/90/120 мин, рабочие часы будней и выходных, опция «Выходные не рабочие»).
     - Понедельный просмотр расписания (по 7 дней на страницу).
     - Блокировка конкретных слотов и целых дат (выходной / отпуск).
     - Ручное заведение записи для клиента (`pro_book_client`).
   - Раздел «Мои клиенты» (при достижении 10 уникальных клиентов включается подписочный гейт 4990 ₽/мес).
   - Переключение в режим «Клиент» и обратно.

3. **Администратор (`admin`)**:
   - Панель администратора (`admin_panel`).
   - Модерация новых анкет специалистов (Одобрить / Отклонить).
   - Управление B2B подписками тренеров (выдача бесплатной бессрочной подписки, эмуляция 1 дня до окончания / истекшей подписки).
   - Генерация тестовых данных (9 mock-клиентов и слотов для тестирования лимитов).
   - Удаление любого пользователя по Telegram ID.

## 2. Сценарии Пользователя (User Flows)

### Flow 1: Старт и Авторизация
1. Пользователь заходит в веб-приложение.
2. Приложение валидирует `initData` от Telegram WebApp (или выставляет токен JWT).
3. Если пользователь новый — открывается экран выбора роли:
   - **«Я профи»** -> переход к онбордингу специалиста.
   - **«Я клиент»** -> быстрая регистрация (имя, город) и переход в каталог.
4. Если пользователь зарегистрирован — открывается Главный экран его активного кабинета (Клиентский или Профессиональный).

### Flow 2: Онбординг и Редактирование Специалиста
1. Шаг 1: Выбор категории (`trainer`, `beauty`, `tennis`, `padel`).
2. Шаг 2: Выбор города и района.
3. Шаг 3: Выбор специализаций (чекбоксы с готовым списком + вариант «Другое»).
4. Шаг 4: Ввод ФИО/Имени и номера телефона.
5. Шаг 5: Опыт работы (лет).
6. Шаг 6: Цены (разовое посещение, пакет за 12 занятий / комплексное обслуживание).
7. Шаг 7: Загрузка фотографий профиля (до 5 штук).
8. Завершение: Аутпут отправляется на модерацию (статус `pending`). Пользователь видит экран «Профиль на рассмотрении».

### Flow 3: Поиск и Бронирование Слота (Клиент)
1. Клиент выбирает фильтр по Городу, Категории и Специализации.
2. Просматривает карточки специалистов (фото, рейтинг, цены).
3. Переходит в карточку специалиста и нажимает **«Забронировать время»**.
4. Открывается календарь доступных дат.
5. При выборе даты открывается список свободных временных слотов.
6. Клиент отмечает 1 или несколько слотов (мультивыбор) и нажимает **«Забронировать время»**.
7. Создается бронирование (статус `confirmed`), формируется уведомление специалисту и клиенту.

### Flow 4: Кабинет Профи и Управление Расписанием
1. Профи открывает «Расписание».
2. Нажимает «Сгенерировать слоты»:
   - Выбирает горизонт (7, 14, 30 дней).
   - Выбирает длительность слота (60, 90, 120 минут).
   - Указывает интервалы для будней и выходных (или включает «Выходные не рабочие»).
3. Слоты автоматически создаются в базе данных.
4. В недельном календаре профи может кликнуть на день/слот для блокировки или отмены.

### Flow 5: B2B Подписка Специалиста (4990 ₽/мес)
1. При попытке просмотреть список «Мои клиенты» (при наличи 10+ клиентов) или при заблокированной подписке появляется модальное окно оплаты.
2. Обязательный чекбокс: «Я согласен с Политикой конфиденциальности» (ссылка `https://cbca.ru/rules/newfit`).
3. Кнопка «Оплатить 4990 ₽/мес» становится активной только после галочки согласие.
4. Оплата проходит через YooKassa / Telegram Payments API. При успехе `is_subscribed = True`, `subscription_expires_at` продлевается на 30 дней.

## 3. База Данных и Модель Данных (SQLAlchemy)

### Сущности и связи:
- **`User`**: Telegram ID (`id`), `full_name`, `username`, `role`, `created_at`.
- **`TrainerProfile`**: Связан с `User` (1:1). Содержит `city`, `district`, `phone`, `experience`, `price_single`, `price_package`, `rating`, `status` (`pending`, `approved`, `rejected`), `is_subscribed`, `subscription_expires_at`.
- **`TrainerPhoto`**: Связан с `TrainerProfile` (1:N). Хранит `file_id`/`url`.
- **`Specialization`** & **`trainer_specializations`**: N:M связь между профилями и специализациями.
- **`ClientProfile`**: Связан с `User` (1:1). `full_name`, `city`, `status`.
- **`TrainerSchedule`**: Настройки генерации (длительность слота, горизонт `rolling_window`, рабочие часы `wd_start`, `wd_end`, `we_start`, `we_end`).
- **`TimeSlot`**: Слоты времени (`start_time`, `end_time`, `status`: `free`, `booked`, `blocked`, `price`). Связан с `TrainerProfile`.
- **`Booking`**: Бронирование слота. Связывает `TimeSlot`, `TrainerProfile` и `ClientProfile`. Статусы: `pending`, `confirmed`, `canceled`, `completed`.
- **`Review`**: Отзывы клиентов (`rating`, `comment`, `booking_id`).
- **`Admin`**: Роли администраторов и права тестирования.

## 4. Архитектура REST API (FastAPI Backend)

Ниже представлена структура REST API эндпоинтов, заменяющих handlers Telegram-бота:

### 4.1 Авторизация и Пользователи (`/api/v1/auth`, `/api/v1/users`)
- `POST /api/v1/auth/telegram`: Аутентификация по Telegram WebApp `initData`, выдача JWT-токена.
- `GET /api/v1/users/me`: Получение текущего профиля и роли пользователя.
- `POST /api/v1/users/switch-role`: Переключение активного кабинета (`client` <-> `pro`).
- `DELETE /api/v1/users/me`: Полное самоудаление аккаунта и всех связанных данных.

### 4.2 Профиль Специалиста и Каталог (`/api/v1/specialists`, `/api/v1/catalog`)
- `GET /api/v1/catalog`: Получение списка анкет с фильтрацией (`city`, `role`, `specialization_id`, `page`).
- `GET /api/v1/specialists/{id}`: Получение полной карточки специалиста (фото, цены, рейтинг, отзывы).
- `POST /api/v1/specialists/profile`: Создание/обновление анкеты специалиста.
- `POST /api/v1/specialists/photos`: Загрузка фото в галерею анкеты.
- `DELETE /api/v1/specialists/photos/{photo_id}`: Удаление фото из галереи.

### 4.3 Управление Расписанием и Слотами (`/api/v1/schedule`, `/api/v1/slots`)
- `GET /api/v1/specialists/{id}/available-dates`: Получение дат с наличием свободных слотов.
- `GET /api/v1/specialists/{id}/slots?date=YYYY-MM-DD`: Получение доступных слотов на выбранный день.
- `POST /api/v1/schedule/quick-generate`: Быстрая генерация слотов по настройкам (период, шаг, часы).
- `POST /api/v1/schedule/block-date`: Блокировка всей даты (создание заблокированного слота 00:00-23:59).
- `DELETE /api/v1/slots/{slot_id}`: Удаление/блокировка одиночного слота.

### 4.4 Бронирования (`/api/v1/bookings`)
- `POST /api/v1/bookings/bulk`: Мультибронирование выбранных слотов клиентом.
- `GET /api/v1/bookings/my`: Список активных и прошлых бронирований текущего пользователя.
- `POST /api/v1/bookings/{id}/cancel`: Отмена бронирования (с отправкой уведомления второй стороне).
- `POST /api/v1/bookings/pro-manual`: Ручное бронирование клиентом со стороны специалиста (`pro_book_client`).

### 4.5 Оплаты и Подписки (`/api/v1/payments`)
- `POST /api/v1/payments/create-subscription-invoice`: Создание счета на 4990 ₽ после подтверждения Privacy Policy.
- `POST /api/v1/payments/webhook`: Webhook от YooKassa / Telegram Payments для активации/продления подписки.
- `GET /api/v1/payments/subscription-status`: Проверка статуса подписки специалиста и количества уникальных клиентов.

### 4.6 Отзывы (`/api/v1/reviews`)
- `POST /api/v1/reviews`: Оставление отзыва и оценки (1-5 звезд) к завершенному бронированию.
- `GET /api/v1/specialists/{id}/reviews`: Список отзывов о специалисте.

### 4.7 Панель Администратора (`/api/v1/admin`)
- `GET /api/v1/admin/pending-specialists`: Список анкет на модерацию.
- `POST /api/v1/admin/moderate/{id}`: Одобрение или отклонение анкеты (`approve`/`reject`).
- `POST /api/v1/admin/grant-free-sub`: Выдача бесплатной вечной подписки по ID.
- `POST /api/v1/admin/emulate-sub`: Эмуляция статуса подписки (1 день остался / истекла).
- `POST /api/v1/admin/generate-test-clients`: Генерация 9 тестовых клиентов.
- `DELETE /api/v1/admin/users/{id}`: Каскадное удаление пользователя.

## 5. Структура Компонентов и Страниц Frontend (React / Vue WebApp)

### 5.1 Список Веб-Страниц (Pages)
1. **`LoginPage` / `WelcomePage`**: Выбор роли («Я профи» / «Я клиент»), знакомство с NewFit.
2. **`CatalogPage`**: Поиск специалистов, фильтры (Город, Категория, Специализация), пагинация карточек.
3. **`SpecialistDetailsPage`**: Профиль специалиста, галерея фото, прайс-лист, отзывы, кнопка «Забронировать время».
4. **`BookingModal` / `SlotPickerDrawer`**: Календарь выбора дат, сетка слотов с мультивыбором, подтверждение бронирования.
5. **`ClientDashboardPage`**: Вкладки «Мои записи», «Избранное», «Профиль».
6. **`ProCabinetPage`**:
   - Вкладка **«Расписание»**: Недельный календарь слотов, кнопка «Сгенерировать слоты», управление выходными/отпуском.
   - Вкладка **«Мои клиенты»**: Список клиентов (с проверкой подписки 10+ клиентов).
   - Вкладка **«Мой профиль»**: Редактирование анкеты, фотогалереи, цен.
7. **`SubscriptionModal`**: Окно оплаты B2B подписки 4990 ₽ с обязательным согласием с Privacy Policy.
8. **`AdminDashboardPage`**: Панель управления модерацией, пользователями и подписками.
